# 数据可用性判定

支持非债券发行人、无评级主体及无公开财务数据实体。规则：使用三允许渠道可可靠获取的任何数据，不伪造数据。

不再检索普通舆情、新闻、工商登记页、发行人网站或第三方聚合器作为降级来源。

## 检索优先级

在中国货币网、上海证券交易所、深圳证券交易所内，按以下优先级检索：

1. 最新年度报告（`report_period >= Y-1` 年，Y = `run_date` 的年份）
2. 最新半年度报告（同上）
3. 最新季度报告（同上）
4. 最新募集说明书
5. 最新评级报告

记录所有匹配允许文件，但年报优先。

## 降级规则

### 年报存在

使用最新年报作为主文档，标记 `selected_main`。半年报和季度报作补充。

### 半年报存在但无年报

使用半年报，明确说明缺少年报。

### 仅有季度报告

季度数据默认仅为补充，不作为完整数据分析基础。

### 无财务报告、有募集说明书

标注来源为募集说明书。设 `data_limitation_note`。

### 无财务报告或募集说明书、有评级报告

标注来源为评级报告。设 `data_limitation_note`。

### 过渡性降级

如 `run_date` 处于当年年报披露尚未完成阶段，可使用 `Y-2` 年年报作为过渡性主文件：
- `transitional_fallback_used=true`
- `data_limitation_note` 必须注明数据滞后

### 无最新公开财务披露

`pdf_handoff.no_latest_public_data=true`，`documents_needing_pdf_parse=[]`。

## 数据级别

- `has_data`：存在至少一个有效文档
- `no_data`：无任何有效文档

## 禁止行为

不得：
1. 伪造财务数据
2. 将工商登记信息作为财务数据
3. 从新闻或舆情推导财务指标
4. 未经主体核验直接使用母公司/子公司/关联方等文件
5. 将「未查询到负面事项」转为正面评论
6. 输出无来源风险判断
